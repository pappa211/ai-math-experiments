## Only accepted certificate formats

- S_COLLAPSE: supplied vertex set S with L-S triangle-free; Z is exactly the outside-S mates of S in P; |P|>|S|+|Z|. The accepted simultaneous-cover theorem applies.

## Full RIM footprint rule, including K4-containing links

This is sufficient under arbitrary outside attachments: any literal old K4/K5 block intersects L in some such clique (or at most one vertex). The entire selected old footprint in that block is exactly A restricted to its L intersection, because the selected triangles use no outside apex and all hub spokes were deleted. The tested footprint is therefore a two-edge star or smaller, avoidable by a maximum K4/K5 packing. Appending |Z|+1>|P| triangles contradicts balanced equality. This rule is conservative but proved; it does not assume L itself is K4-free.
